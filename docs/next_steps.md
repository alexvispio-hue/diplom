# Следующие шаги

Актуальный план развития находится в [product_roadmap.md](product_roadmap.md).

Ближайший приоритет после версии 0.2.0:

1. Завершить подготовку и валидацию HWR200.
2. Дообучить Qwen на полных страницах и измерить CER/WER на закрытом test split.
3. Добавить автоматическую оценку качества фотографии и выбор предобработки.
4. Реализовать фоновую очередь документов с отменой и восстановлением.
5. Провести чистую установку релизного ZIP на отдельном компьютере Windows.

Текущий baseline TrOCR сохраняется как быстрый режим для слов, фрагментов и выделенных строк. Qwen развивается как основная модель полных страниц и сложной компоновки.
