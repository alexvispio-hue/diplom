# Установка Handwriting OCR

Приложение работает локально: изображения, распознанный текст и история сохраняются на компьютере пользователя. Внешний OCR API не используется.

## Требования

- Windows 10/11 x64;
- Python 3.10 или новее;
- подключение к интернету во время первой установки и первой загрузки весов модели;
- не менее 10 ГБ свободного места для окружения, кэша и базовой модели;
- NVIDIA GPU рекомендуется для режимов Qwen, но базовый TrOCR может работать на CPU.

## Установка в Windows

1. Распакуйте релизный архив в папку, доступную текущему пользователю.
2. Запустите `INSTALL_WINDOWS.bat`.
3. После завершения запустите `START_APP.bat` или ярлык `Handwriting OCR` на рабочем столе.

Установщик создаёт изолированное окружение `.venv-app`, ставит зависимости и создаёт локальный файл `.env`. Пользовательские данные хранятся в папке `data`, веса моделей — в `models` и кэше Hugging Face.

При запуске открываются:

- приложение: `http://127.0.0.1:8501`;
- документация API: `http://127.0.0.1:8000/docs`.

Остановка выполняется закрытием окна запуска или сочетанием `Ctrl+C`.

## Локальная модель

Если в `models` нет подходящего checkpoint, TrOCR загружается из Hugging Face при первом распознавании. После загрузки модель работает локально и может использоваться без сети.

Для Qwen можно указать:

- preset в `.env` через `QWEN_MODEL_PRESET=light`;
- Hugging Face id через `QWEN_MODEL_NAME`;
- локальный путь к модели через `QWEN_MODEL_NAME`;
- путь к LoRA-адаптеру через `QWEN_LORA_ADAPTER_DIR`.

## Docker

При установленном Docker Desktop приложение запускается командой:

```powershell
docker compose up --build
```

Compose поднимает API и интерфейс, монтирует `data` и `models`, а также сохраняет кэш Hugging Face в отдельном volume.

## Настройки

Основные параметры находятся в `.env`:

```dotenv
MAX_UPLOAD_SIZE_MB=10
MAX_DOCUMENT_PAGES=100
PDF_RENDER_DPI=160
QWEN_MODEL_PRESET=light
```

После изменения `.env` приложение нужно перезапустить.

## Сборка релиза

Компактный архив без датасетов, весов моделей, истории и временных файлов собирается командой:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_release.ps1
```

Готовый ZIP появляется в `dist`. Его можно приложить к GitHub Release или передать пользователю напрямую.

Перед публичной публикацией необходимо отдельно выбрать лицензию проекта и проверить лицензии распространяемых весов моделей. Веса моделей рекомендуется публиковать отдельно от приложения.
