# Дорожная карта Handwriting OCR

## Текущее состояние: 0.2.0

Версия 0.2.0 формирует первый пользовательский релиз:

- локальное распознавание TrOCR и Qwen;
- несколько режимов обработки страницы;
- загрузка нескольких изображений и PDF;
- очередь страниц с прогрессом обработки;
- единый редактируемый текст документа;
- экспорт в TXT, JSON и DOCX;
- история, оценки качества и очередь ручной проверки;
- установка в Windows и запуск одной командой;
- Docker-конфигурация для API и интерфейса;
- релизный ZIP без датасетов, моделей и пользовательских данных.

## 0.3: качество распознавания

1. Завершить подготовку HWR200 и обучение страницы Qwen.
2. Зафиксировать отдельный test split по авторам и не использовать его при настройке.
3. Добавить автоматический отчёт CER/WER, времени и расхода видеопамяти для каждой версии модели.
4. Реализовать маршрутизатор моделей: быстрый TrOCR для простых строк, Qwen для полных или сложных страниц.
5. Добавить оценку качества входного изображения: размытие, засветка, низкий контраст, наклон и перспектива.
6. Выбирать предобработку автоматически, но оставлять пользователю ручное управление.

Критерий готовности: версия модели воспроизводимо превосходит baseline на закрытом тестовом наборе, а обновление не ухудшает простые фрагменты.

## 0.4: рабочий процесс документов

1. Фоновая очередь с отменой, повторным запуском и восстановлением после перезапуска.
2. Импорт папки и автоматическая сортировка страниц по имени и метаданным.
3. Поворот, обрезка листа и коррекция перспективы до OCR.
4. Визуальный слой поверх страницы: строка, её координаты и связанный фрагмент текста.
5. Ручная перестановка строк и страниц перетаскиванием.
6. Экспорт в searchable PDF с текстовым слоем.
7. Автосохранение незавершённой правки документа.

## 0.5: настольное приложение

1. Оболочка на PySide6 или Tauri вместо обязательной вкладки браузера.
2. Менеджер моделей: установка, выбор, проверка контрольной суммы и удаление весов.
3. Профили установки CPU, NVIDIA GPU и компактный режим только с TrOCR.
4. Подписанный Windows-инсталлятор и корректное удаление приложения без удаления пользовательских документов.
5. Автоматическая проверка обновлений с явным согласием пользователя.
6. Резервное копирование базы, исправлений и настроек.

## 0.6: интеллектуальные функции

1. Active learning: отбирать для разметки не все результаты, а наиболее полезные спорные страницы.
2. Локальная проверка орфографии с отображением отличий, без скрытой замены исходного OCR-текста.
3. Поиск по распознанным конспектам и документам.
4. Теги, проекты и объединение страниц в коллекции.
5. Сравнение версий распознавания после обновления модели.
6. Профиль почерка пользователя как опциональный локальный адаптер.

## Публикация

Для публичного релиза необходимо:

1. Выбрать лицензию исходного кода и отдельно проверить лицензии весов и датасетов.
2. Добавить CI для тестов, проверки сборки ZIP и Docker-образа.
3. Публиковать приложение и веса моделей раздельно.
4. Добавлять SHA-256 для архивов и моделей.
5. Подготовить короткую политику приватности: какие данные хранятся, где они находятся и как их удалить.
6. Провести тест чистой установки на компьютере без Python-окружения проекта.

## Инженерные задачи

- перейти от ручных SQL-миграций к Alembic;
- добавить структурированные журналы и экран диагностики без чувствительных данных;
- ограничить сроки хранения временных изображений;
- добавить удаление, архивирование и резервное копирование истории;
- покрыть браузерными тестами загрузку, пакетное распознавание, экспорт и обратную связь;
- измерять время холодного и повторного запуска каждой модели;
- не включать телеметрию по умолчанию; возможная диагностика должна быть добровольной.
