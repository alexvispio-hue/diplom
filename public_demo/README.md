# Онлайн-демо Handwriting OCR

Самостоятельный экран распознавания фрагментов для Streamlit Community Cloud. Не запускает FastAPI и не подключает общую базу данных, историю, загрузку локальных папок и инструменты обучения.

**Распознавание целого листа текста не работает.** Загружайте слово или небольшой фрагмент. На фотографии страницы можно вручную выделить одну строку.

## Развёртывание

1. Открыть https://share.streamlit.io/ и войти в свой аккаунт.
2. Создать приложение из репозитория `alexvispio-hue/diplom`, ветка `main`.
3. Entrypoint: `public_demo/streamlit_app.py`.
4. В Advanced settings выбрать Python **3.11**.
5. Нажать Deploy и дождаться установки зависимостей. `public_demo/requirements.txt` имеет приоритет перед зависимостями корня репозитория.
6. Открыть выданный адрес, загрузить фрагмент и проверить реальное распознавание. Только после этого добавлять адрес в резюме.

Ресурсы Community Cloud ограничены и могут меняться. Если загрузка модели не помещается в RAM, понадобится другая площадка или более компактная модель; не подменяйте рабочее распознавание заранее записанными ответами.

## Модель

По умолчанию загружается публичная `kazars24/trocr-base-handwritten-ru`. Это базовая модель проекта, а не дообученный локальный checkpoint. Различие явно указано на странице. Локальные веса не публикуются этим демо и не попадают в Git.

В своей среде можно задать переменную `OCR_DEMO_MODEL` с путём к совместимому TrOCR checkpoint или ID опубликованной модели. Перед публикацией весов проверьте право их распространения. Демо использует CPU и safetensors, без выполнения remote code.

## Локальная проверка

```powershell
python -m pip install -r public_demo/requirements.txt
python -m streamlit run public_demo/streamlit_app.py
```

Изображения и ответы живут в памяти текущего сеанса Streamlit, без файлов и общей истории. Модель общая для процесса; при занятом распознавателе второй посетитель получает предложение повторить запрос. Допускается один PNG/JPEG/WEBP до 5 МБ и 12 Мп, не более 96 новых токенов результата.

Документация размещения: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy.
